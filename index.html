{% comment %} One list per year range from group.publication_range_starts, plus a final "Before " range. Every range is in the page; the inline script below shows the picker and hides all but the chosen range, so without JavaScript the picker stays hidden and the whole list shows, newest first. Hiding uses the `hidden` attribute, which also takes the other ranges out of the accessibility tree, so a screen reader hears only what is shown. The chosen range is kept in the URL as ?pubs=, where the key is the range's first year (or before- for the oldest), so a link keeps pointing at the same years when ranges are added above it. The newest range is the default and leaves the parameter off.
