# Historical reading-order reader captures

These Firefox AT-SPI captures and the partial Orca speech attempt describe the
PDF hashes recorded in `results.json` at the end of the reading-order phase.
Subsequent PDF/UA changes altered those hashes. The historical verifier therefore
does not apply to the current PDFs.

Use the [fresh PDF/UA reader captures and verification instructions](../../../../pdfua/at/README.md)
for current files. The [group report](../README.md) preserves the earlier setup,
assertions and audio-backend limitation. No continuous screen-reader speech
claim is made for either phase.
