{% comment %} Renders CV publication entries (cv_publication_item.html) for one CV section, in venue-year-descending order. Each entry's numbering code (J.45, C.31, ...) comes from the cv_publication_codes filter defined in _plugins/cv_publication_codes.rb: the letter from _data/publication_types.yaml, the number from the paper's position in its section's sequence. Parameters: all_publications publication records to draw from. venues venue records sorted year-descending; defines the render order. allowed_types array of venue type strings for this section (from _data/cv_publication_sections.yaml). highlight_id people.yaml id whose name is emphasized in the author list -- the CV's subject. pub_codes publication id -> numbering code map, built once by the caller with the cv_publication_codes filter. The map is global across sections, so it must be built from *all* publications, not this section's subset -- and a section's own numbers are not contiguous when another section is a split view of the same types. {% endcomment %} {% assign pub_codes = include.pub_codes %} {% for venue in include.venues %} {% unless include.allowed_types contains venue.type %}{% continue %}{% endunless %} {% assign venue_pubs = include.all_publications | where: "venue", venue.id %} {% for pub in venue_pubs %} {% assign pub_code = pub_codes[pub.id] %} {% include cv_publication_item.html pub=pub venue=venue pub_code=pub_code highlight_id=include.highlight_id %} {% endfor %} {% endfor %}
