{% comment %} Renders CV publication entries (cv_publication_item.html) for one CV section, in venue-year-descending order. Each entry's numbering code (J.12, C.31, ...) comes from the cv_publication_codes filter defined in _plugins/cv_publication_codes.rb, using the prefixes in _data/publication_types.yaml. Parameters: all_publications publication records to draw from. venues venue records sorted year-descending; defines the render order. allowed_types array of venue type strings for this section (from _data/cv_publication_sections.yaml). pub_codes publication id -> numbering code map, built once by the caller with the cv_publication_codes filter. The map is global across sections, so it must be built from *all* publications, not this section's subset. {% endcomment %} {% assign pub_codes = include.pub_codes %} {% for venue in include.venues %} {% unless include.allowed_types contains venue.type %}{% continue %}{% endunless %} {% assign venue_pubs = include.all_publications | where: "venue", venue.id %} {% for pub in venue_pubs %} {% assign pub_code = pub_codes[pub.id] %} {% include cv_publication_item.html pub=pub venue=venue pub_code=pub_code %} {% endfor %} {% endfor %}
