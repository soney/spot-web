{% comment %} A person's links as a breadcrumb list: their homepage, then their name pronunciation recording, then any extra links from their people.yaml record. The recording (name_recording, an audio path under assets/) renders as a "Hear my name" link that plays in place -- the behaviour lives in _includes/name_recording_script.html, keyed off the data-name-recording attribute, and the href is the audio file itself so the link still works without JavaScript. An extra link to a service listed in _data/link_icons.yaml (Google Scholar, GitHub, ...) gets that service's icon in front of its description; any other link renders as plain text. Parameters: person the person record (from people.yaml). local_homepage when true, a person with use_local_homepage: true gets a "Homepage" link to their /people// page instead of their external homepage.
